[#715](https://github.com/cursor/plugins/pull/715) (`f9be7aa0`) does not bump the version. It offers formal verification from `/setup-pstack` and syncs help and the guide. 0.15.28 ([#724](https://github.com/cursor/plugins/pull/724), `d4575673`) includes the TLA+ default and the no-verifier fallback in `/create-formal-verification-skill` ([#721](https://github.com/cursor/plugins/pull/721)) and `/maintain-formal-verification-skill` ([#716](https://github.com/cursor/plugins/pull/716)). `/setup-pstack` does not offer the maintain skill, because upstream does not. Skill files stay at `skills/<name>/SKILL.md`. 0.15.29 ([#729](https://github.com/cursor/plugins/pull/729), `88d47514`) returns `/sharpen` to the original prompt. It names four things: what a top professional would add, the rawest starting material, the methods and tools, and an outside check. Then it rewrites the prompt, leaves the user's choices open, and does not do the task. `/poteto-help`, its recipes, and guide pages 2 and 10 say the same. 0.15.30 ([#741](https://github.com/cursor/plugins/pull/741), `eb4db2b55b`, 2026-10-22) adds `/statechart`. The skill draws what the user sees as a Mermaid statechart generated from a TLA+ model. TLC checks the reader's rules as invariants. Each state is marked works, still wrong, or fixed by an open change, and each bug TLC finds is a numbered path. It also turns an agreed chart into a TLA+ skeleton, compares the drawn chart with the agreed one, and can audit the code against an existing spec. `/poteto-help` and guide page 6 name the same entry. No other `pstack/` commit sits between 0.15.29 and 0.15.30. 0.15.32 ([#798](https://github.com/cursor/plugins/pull/798), `e73df471cd`, 2026-10-23) is this pin. It includes 0.15.31 ([#792](https://github.com/cursor/plugins/pull/792)). `/statechart` then takes six fixes ([#776](https://github.com/cursor/plugins/pull/776)), a comment and helper cleanup ([#779](https://github.com/cursor/plugins/pull/779)), and the Pele renderer ([#791](https://github.com/cursor/plugins/pull/791)). PNGs come from Pele and resvg. When `TLA2TOOLS` is unset, the first run installs TLC and Java with mise. The chart draws how any system moves between states, not only what a user sees, and a broken PROPERTY has no path on the chart. `/create-formal-verification-skill` tells a generated verify skill to read each model-check result with `/statechart` ([#794](https://github.com/cursor/plugins/pull/794)). `/ketchup-video` shows the `/ketchup` catch-up as a short silent video of slides, with the calls waiting on the user as text under it ([#797](https://github.com/cursor/plugins/pull/797)). `/poteto-help` and guide page 10 name that entry. `/reflect` copies a skill out of `plugins/cache/` before it edits the copy, and it does not open a PR ([#800](https://github.com/cursor/plugins/pull/800)). `watch-pr` tells fork heads apart while it discovers a stack ([#801](https://github.com/cursor/plugins/pull/801)) and caps a poll sleep at the deadline ([#802](https://github.com/cursor/plugins/pull/802)). `check-plan` treats a matching run of backticks as one code span ([#803](https://github.com/cursor/plugins/pull/803)). The orch store prefers an open PR over older branch history ([#804](https://github.com/cursor/plugins/pull/804)). `worktree-audit` reads transcript mtimes with GNU `stat` and `date` ([#805](https://github.com/cursor/plugins/pull/805)). `/swarm` numbers Phase A from 1 to 4, and Phase D asks for a result table ([#807](https://github.com/cursor/plugins/pull/807)). The pin commit is the tip of `cursor/plugins` main and includes the pstack fixes after the 0.15.32 bump, through [#807](https://github.com/cursor/plugins/pull/807).
